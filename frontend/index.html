多智能体闭环

            
用户自然语言
    │
    ▼
┌──────────────────┐
│  意图理解 Agent   │  classify_intent + 实体抽取
└────────┬─────────┘
         ▼
┌──────────────────┐
│  编排器 Router    │  按意图分发
└────────┬─────────┘
    ┌────┼────┬─────────┬──────────┐
    ▼    ▼    ▼         ▼          ▼
  链路   波束  干扰    诊断      优化/报告
  Agent  Agent Agent   Agent     Agent
    │    │     │        │          │
    └────┴─────┴────────┴──────────┘
                 │
                 ▼
        确定性仿真引擎（路损 / 香农 / 阵列因子 / SINR）
                 │
                 ▼
        运维台（对话 / 曲线 / 报告）

            
三条设计原则

            
    
              
  • LLM 只管说人话，指标全部来自确定性仿真 —— 结果可复现、可审计。
    • 
              
  • 模型可插拔：右上角「模型设置」可在本地演示 / OpenAI / DeepSeek / Kimi / 千问 / GLM 间切换。
    • 
              
  • 通信专业可解释：路损、香农、阵列因子、SINR 都给公式和工程结论。
    •
