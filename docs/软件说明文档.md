# CommAgent 软件说明文档（AI+软件创新）

## 1. 产品概述

| 项 | 内容 |
|----|------|
| 软件名称 | CommAgent · 6G通感算智网络智能运维体 |
| 版本 | v1.0 |
| 类型 | AI 赋能的通信网络运维与仿真软件（桌面 + 本地 Web 控制台） |
| 目标用户 | 运营商/设备商网优工程师、通信专业师生、6G 场景预研人员 |
| 运行平台 | Windows 10/11 x64（亦可源码运行于 macOS / Linux） |

**一句话定位**：用自然语言下达运维意图，由多智能体调用确定性通信仿真引擎，给出可复现的链路/波束/干扰/诊断/优化结论，并自动成文。

## 2. 核心功能

| 模块 | 功能 | 算法 |
|------|------|------|
| 运维对话 | 多轮自然语言、意图识别、知识融合 | LLM + 关键词实体抽取 |
| 链路预算 | 路损、SNR、香农容量、覆盖曲线 | 3GPP UMa / Shannon |
| 波束赋形 | ULA 方向图、3dB 波束、多用户分配 | 阵列因子 + 单元方向图 |
| 干扰分析 | 同频合并、SINR、主干扰源 | 线性域干扰合并 |
| KPI 诊断 | 根因卡片与处置建议 | 覆盖→干扰→负载→参数规则链 |
| 功率优化 | 基站功率局部搜索 | 干扰受限下的吞吐最大化搜索 |
| 运维报告 | 自动汇编仿真与诊断 | 模板 + LLM 润色 |
| 模型设置 | 本地演示 / OpenAI 兼容 API 热切换 | 可插拔 LLM 端口 |

## 3. 技术架构

```
Web 控制台（对话 / 仿真 / 诊断 / 报告）
        │
   FastAPI REST
        │
  多智能体编排器（意图 → Agent）
        │
  确定性仿真引擎（路损 / 波束 / 干扰 / 场景 / 优化）
        │
  知识库 + 可插拔 LLM（Mock / OpenAI 兼容）
```

**技术栈**：Python 3.11 · FastAPI · Uvicorn · Pydantic · HTTPX · 原生 Canvas 图表（零前端框架依赖）· PyInstaller 打包。

**创新点**：
1. LLM 与确定性仿真分离——指标可复现、可审计，避免大模型「编数字」。
2. 概念原理题由知识库增强的 LLM 自然讲解；带数值的任务走仿真引擎。
3. 模型可插拔：现场无网用本地演示引擎，有 Key 时一键切云端，答辩不中断。
4. 图表高清可交互（悬停读点），适合投影演示。

## 4. 安装与运行

### 4.1 桌面版（推荐提交）

1. 解压 `CommAgent-win64.zip`
2. 双击 `CommAgent.exe` 或 `启动 CommAgent.bat`
3. 浏览器自动打开控制台（默认 `http://127.0.0.1:8787`）
4. 关闭控制台窗口即退出

### 4.2 源码运行

```bash
pip install -r requirements.txt
python run.py --llm mock --port 8787
```

### 4.3 模型配置

右上角「模型设置」：本地演示 / OpenAI / DeepSeek / Kimi / 千问 / GLM / 自定义端点。  
配置保存在 `outputs/llm_config.json`（仅本机）。

## 6. 应用价值

- **网优排障**：KPI 一键根因，缩短定位时间。
- **覆盖规划**：链路预算与覆盖曲线快速 what-if。
- **教学实验**：香农/路损/波束可视化，公式可核对。
- **6G 预研**：通感算智运维叙事，可扩展低空/空天地场景。

## 7. 安全与合规

- API Key 仅存本地配置文件，不上传。
- 路损/天线公式基于 3GPP 公开模型与经典阵列理论。
- 无外部强制联网依赖，离线可演示核心能力。
